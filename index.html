Help & deployment

1. Put DreamWorld.html in a public GitHub Pages repository and enable GitHub Pages. HTTPS is the supported way to use model caching and module workers; direct file:// opening may fail.

2. Add your DeepSeek API key in Settings. Create a story. DreamWorld plans it, generates its first page and 3D scene, then builds the other pages progressively.

3. Load Phonon TTS in Settings, select a voice, and press Play in Storybook. Narration is generated locally. Enable the optional audio alignment model if you want real audio-derived word timings; it may be slow on a Chromebook and can fail validation.

4. Stories are saved in IndexedDB, including completed audio. Browser storage can be cleared by Chrome; export your story JSON for backup. JSON backups omit large audio blobs.

5. The default public English checkpoint cannot narrate French, German, Spanish, or Portuguese. Those voices are browseable, but require a compatible multilingual/language-specific checkpoint that you provide. Audio recording cannot be converted into a voice embedding by this HTML.

External downloads: Three.js, Phonon WASM worker/model, Gradium catalog/voices, optionally Transformers.js and a Whisper alignment model. There are no paid narration API calls: DeepSeek generation uses your API key.
